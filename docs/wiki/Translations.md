# Translations

English is the source edition for all seven wiki languages. Update every language edition when the English content changes.

For an update, change the corresponding pages in every available language. Keep commands, paths, test names, measurements, and warnings consistent. Record unresolved translation differences instead of hiding them.

All wiki topics have editions in English, Persian, Russian, Simplified Chinese, Arabic, Turkish, and Urdu. Translations cover the English guide content, including warnings and upstream credits. Automated checks compare page coverage, code examples, and links. The updated translations still need independent native-speaker review.
