处理器和内存：Caspian 尚未通过测量确定最低内存容量、处理器核心数或时钟频率。资源占用取决于流量、代理协议和并发连接数。发布最低配置要求前，需要测量空闲和负载状态下的资源占用。

Linux 发布版本面向 x86-64、ARM64 和 ARMv6/ARMv7。架构兼容本身并不能证明性能足以满足使用需求。
