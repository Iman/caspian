# 翻译

英语是所有七种维基语言的源版本。当英文内容发生变化时更新各个语言版本。

如需更新，请更改每种可用语言的相应页面。保持命令、路径、测试名称、测量和警告一致。记录未解决的翻译差异而不是隐藏它们。

所有维基主题都有英语、波斯语、俄语、简体中文、阿拉伯语、土耳其语和乌尔都语版本。翻译涵盖英文指南内容，包括警告和上游制作人员名单。自动检查会比较页面覆盖率、代码示例和链接。更新后的翻译仍需要独立的母语人士审核。
