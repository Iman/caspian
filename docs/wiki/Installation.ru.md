<a id="installing"></a>
## Установка

Сначала выберите операционную систему. Windows и macOS имеют графические установщики;
Linux и Raspberry Pi можно установить автоматически, сначала проверить или собрать
из источника.

<a id="windows-10-and-11"></a>
### Windows 10 и 11

Программа установки устанавливает все, что нужно Каспиану. Вам не нужно
PowerShell, Go или .NET SDK.

<a id="what-you-need"></a>
#### Что вам нужно

- Компьютер под управлением Windows 10 версии 2004 (сборка 19041) или более поздней версии либо Windows 11 на платформе x64 или ARM64.
Установщик отклоняет все, что старше Windows 10 версии 1607, которая является
сначала с мобильной точкой доступа. Между 1607 и 1909 годами Caspianские инсталляции и панно
открывается, но в соединении отказано с сообщением о версии: эти сборки
у меня нет возможности отправлять запросы по имени через туннель, и Каспиан не вбежит
состояние, в котором имена либо просачиваются, либо перестают разрешаться.
- Учетная запись администратора на этом компьютере.
- Адаптер Wi-Fi, поддерживающий точку доступа Windows Mobile.
- Подключение к Интернету.
- Поддерживаемая прокси-ссылка или конфигурация.

<a id="choose-the-correct-download"></a>
#### Выберите правильную загрузку

Большинство компьютеров Intel и AMD используют установщик x64:

- `CaspianSetup-0.2.1-windows-x64.exe`

Компьютеры Windows с процессором Snapdragon или другим процессором ARM используют ARM64.
установщик:

- `CaspianSetup-0.2.1-windows-arm64.exe`

Если вы не знаете тип своего компьютера, откройте **Настройки**. Выберите **Система**,
затем **О**. Прочтите строку **Тип системы**.

<a id="install-caspian"></a>
#### Установить Каспиан

1. Откройте [Страница релиза Caspian моря](https://github.com/Iman/caspian/releases/latest).
2. Разверните раздел **Активы** в последней версии.
3. Загрузите правильный установщик Windows.
4. Дважды щелкните загруженный файл.
5. Если появится SmartScreen, выберите **Подробнее**.
6. Убедитесь, что в предупреждении издателя указан файл, который вы скачали.
7. Выберите **Все равно выполнить**.
8. Выберите **Да**, когда Windows запрашивает доступ администратора.
9. Прочтите страницу лицензии и продолжайте.
10. Выберите пароль для веб-панели «Caspian».
11. Введите тот же пароль еще раз.
12. Храните этот пароль в надежном месте.

Мастер установки также показывает два дополнительных варианта:

- **Создайте ярлык на рабочем столе**
- **Запуск Caspian Контроля после входа в систему**

Оба варианта отключены по умолчанию. Программа установки всегда создает **Caspian Control**
ярлык в меню «Пуск» Windows. Когда установка завершится, оставьте **Открытый Каспиан.
Выделите элемент управления** и нажмите **Готово**.

Windows может отображать предупреждение **Неизвестный издатель**, пока установщик не получит
сертификат подписи кода. Проверьте, что файл пришел с официального Каспия
освободите страницу, прежде чем продолжить.

![Caspian Control on Windows](https://github.com/Iman/caspian/blob/main/docs/images/caspian-control-windows.png)

<a id="the-two-caspian-windows"></a>
#### Два каспийских окна

У Каспиана есть два разных экрана управления в Windows.

| Экран | Где он открывается | Что он контролирует |
|---|---|---|
| **Caspianский контроль** | Небольшое приложение Windows и значок в области уведомлений. | Запускает, останавливает или перезапускает фоновые службы Каспия. |
| **Caspian веб-панель** | Ваш веб-браузер по адресу `http://127.0.0.1:8088/`. | Устанавливает имя Wi-Fi, пароль Wi-Fi, диапазон частот и прокси-соединение. |

Сначала используйте **Caspian Control**. Подождите, пока появится сообщение **Готово**, затем выберите **Открыть панель**.
Веб-панель — это второй экран. Используйте его, чтобы запустить точку доступа и туннель.

**Готовность** в «Caspian Control» означает, что отвечают две справочные службы.
Это не означает, что прокси-туннель подключен. Веб-панель станет зеленой
когда точка доступа и туннель будут готовы.

<a id="first-start"></a>
#### Первый старт

1. Откройте **Caspian Control** из меню «Пуск» или на рабочем столе Windows.
2. Выберите **Да**, когда Windows запрашивает доступ администратора.
3. Выберите **Начать все**.
4. Подождите, пока на большой карточке не появится сообщение **Готово**.
5. Выберите **Открыть панель**.
6. Введите пароль панели, который вы выбрали во время настройки.
7. Выберите **Войти**.
8. Введите имя новой сети Wi-Fi.
9. Введите пароль Wi-Fi длиной не менее восьми символов.
10. Оставьте **2,4 ГГц** для лучшей поддержки старых устройств.
11. Вставьте ссылку или конфигурацию прокси-сервера.
12. Выберите переключатель, чтобы запустить Каспиан.
13. Подождите, пока статус веб-панели не станет зеленым.
14. Подключите свой телефон или другое устройство к новой сети Wi-Fi.
15. Откройте веб-сайт на этом устройстве, чтобы проверить соединение.

На панели отображается каждое подключенное устройство. Windows дает этим адресам устройств
из `192.168.137.0/24`. Каспиан передает свой интернет-трафик через
`xray0` туннель.

Пароль панели и пароль Wi-Fi разные. Открывается пароль панели
веб-панель. Пароль Wi-Fi соединяет телефоны и другие устройства.

<a id="what-the-caspian-control-buttons-do"></a>
#### Что делают кнопки «Caspian Control»

| Контроль | Результат |
|---|---|
| **Начать все** | Запускает обе фоновые службы Caspian региона. |
| **Остановить всё** | Останавливает обе службы и оставляет их остановленными. |
| **Перезапустить все** | Останавливает и запускает обе службы |
| **Открытая панель** | Открывает веб-панель «Caspian» в вашем браузере. |

Приложение остается в области уведомлений Windows после закрытия его окна.
Область уведомлений находится рядом с часами. Дважды щелкните значок Каспия, чтобы
откройте приложение еще раз.

<a id="what-to-expect"></a>
#### Чего ожидать

Windows запрашивает доступ администратора, потому что Каспиан меняет сетевые маршруты,
брандмауэр, мобильную точку доступа и сетевой адаптер Wintun.

Windows отключает устройства, когда вы останавливаете или перезапускаете точку доступа. Подождите
веб-панель станет зеленой, а затем снова подключите каждое устройство.

Если компания «Caspian Control» сообщает **Готово**, но веб-панель горит красным, прочитайте сообщение в
веб-панель. Веб-панель проверяет точку доступа и прокси-туннель.

<a id="developer-requirements"></a>
#### Требования разработчика

Приведенный ниже метод PowerShell предназначен для разработчиков. Из этого он строит Caspian
репозиторий и устанавливает службы Windows.

Для этого метода необходимы следующие дополнительные программы:

- Учетная запись администратора.
- Активное подключение к Интернету.
- Адаптер Wi-Fi, поддерживающий точку доступа Windows Mobile.
- [Git для Windows](https://git-scm.com/download/win).
- [Перейти на версию 1.26 или новее](https://go.dev/dl/).
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

Программа установки и метод разработчика поддерживают системы Windows x64 и ARM64.

<a id="developer-install"></a>
#### Установка разработчика

1. Откройте PowerShell.
2. Клонируйте этот репозиторий.
3. Перейдите в каталог репозитория.
4. Запустите установщик Windows.

```powershell
git clone https://github.com/Iman/caspian.git
Set-Location caspian
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\windows\install.ps1
```

5. Нажмите **Да**, когда Windows запросит доступ администратора.
6. Дождитесь завершения сборки и установки службы.

Установщик выполняет следующие задачи:

- Собирает `caspian.exe` для текущего компьютера.
- Создает помощник Windows Mobile Hotspot.
- Создает приложение лотка `CaspianControl.exe`.
- Загружает Wintun 0.14.1 при отсутствии `wintun.dll`.
- Сравнивает архив Wintun с его фиксированным значением SHA-256.
- Устанавливает программы в `C:\Program Files\Caspian`.
- Создает службы Windows `caspian` и `caspian-panel`.
- Устанавливает автоматический запуск обеих служб.
- Создает ярлык **Caspian Control** на рабочем столе.
- Ожидает до 45 секунд для локальной панели.
- Открывает Каспиан Контроль после ответа панели.

Используйте `-NoOpen` для установки, не открывая приложение в трее:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\windows\install.ps1 -NoOpen
```

<a id="repair-or-update"></a>
#### Ремонт или обновление

Запустите тот же установщик еще раз. Установщик останавливает службы, заменяет
программы, сохраняет состояние панели и снова запускает службы.

<a id="uninstall"></a>
#### Удалить

Откройте PowerShell администратора в репозитории. Затем запустите:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\windows\uninstall.ps1
```

Деинсталлятор удаляет службы Windows и установленные программы. Прочтите
сценарий перед использованием, когда вам нужно сохранить локальное состояние.

<a id="macos-13-or-later"></a>
### macOS 13 или новее

Образ диска macOS содержит собственное приложение **Caspian Control** и
Caspianский двигатель. Вам не нужны Терминал, Go, Homebrew или другая среда выполнения.
Вам нужна учетная запись администратора, и, если встроенный Wi-Fi является точкой доступа,
проводное подключение к Интернету Ethernet.

<a id="choose-the-correct-download-1"></a>
#### Выберите правильную загрузку

- В компьютерах Intel Mac используется `Caspian-v0.2.4-macos-amd64.dmg`.
- На компьютерах Apple Silicon Mac (M1 или новее) используется `Caspian-v0.2.4-macos-arm64.dmg`.

Откройте **Меню Apple → Об этом Mac**, если вы не знаете, есть ли на Mac
Процессор Intel или кремний Apple.

<a id="install-and-approve-the-first-opening"></a>
#### Установить и утвердить первое открытие

Приложение версии 0.2.4 подписано специально, но еще не подписано разработчиком Apple.
Удостоверение личности или нотариально заверенное Apple. Поэтому гейткипер показывает **«Caspian» не открыт**.
и говорит, что Apple не смогла убедиться в отсутствии вредоносного ПО. Это не
сбой приложения. Отменить предупреждение только для файла, загруженного с
официальная страница релиза Каспия.

1. Откройте [последний каспийский релиз](https://github.com/Iman/caspian/releases/latest).
и разверните **Активы**.
2. Загрузите DMG для процессора Mac и откройте его.
3. Перетащите `Caspian.app` в папку **Приложения**.
4. Откройте копию в разделе **Приложения** один раз.
5. Когда Gatekeeper заблокирует его, нажмите **Готово**.
6. Откройте **Меню Apple → Системные настройки → Конфиденциальность и безопасность**.
7. Прокрутите до пункта **Безопасность** и нажмите **Все равно открыть** рядом с надписью «Caspian». Кнопка
остается доступным в течение примерно одного часа после заблокированной попытки открытия.
8. Введите пароль для входа в Mac, нажмите **ОК**, затем подтвердите **Открыть**.

macOS сохраняет это приложение как исключение, поэтому последующие открытия выполняются двойным щелчком мыши.
это нормально. Apple документирует тот же процесс в
[Откройте приложение, переопределив настройки безопасности.](https://support.apple.com/guide/mac-help/apple-cant-check-app-for-malicious-software-mchleab3a043/26/mac/26).

<a id="if-macos-still-blocks-the-background-service"></a>
#### Если macOS по-прежнему блокирует фоновую службу

Установленный фоновый исполняемый файл `/usr/local/bin/caspian` может сохранять
пометка карантина после того, как вы одобрите `Caspian.app`. Имена предупреждений в нижнем регистре
`caspian`, и в окне управления появится сообщение **Caspian требует внимания**.

**Если в предупреждении упоминается Trojan или сообщается о вредоносном ПО, не используйте приведенную ниже команду.**
Остановите настройку и сообщите точное оповещение, имя обнаружения, версию выпуска и
URL-адрес загрузки в формате [Проблема с GitHub](https://github.com/Iman/caspian/issues).
Обнаружение вредоносного ПО требует расследования; неподписанный выпуск сам по себе не
установить, что обнаружение является ложным. См.
[Объяснение Apple предупреждений безопасности macOS](https://support.apple.com/en-ie/102445).

Используйте этот запасной вариант только для предупреждения о непроверенном разработчике или ненотариально заверенном приложении.
после того, как вы доверяете файлу и его источнику. Скачать релиз с официального сайта
Страница выпуска Каспиана и сравните контрольную сумму DMG с опубликованной
`SHA256SUMS`. Соответствующая контрольная сумма подтверждает выпуск файла, а не его безопасность.

1. Откройте **Терминал**.
2. Удалите флаг карантина из установленного фонового исполняемого файла:

   ```bash
   sudo xattr -d com.apple.quarantine /usr/local/bin/caspian
   ```

3. Введите пароль для входа в Mac. Терминал не отображает пароль при вводе.
4. В Каспии выберите **Дополнительные параметры → Перезапустить службы**.

Эта команда удаляет только атрибут карантина именованного файла. Это не
отсканируйте, подпишите или нотариально заверьте исполняемый файл. Если Терминал сообщает `No such xattr`,
атрибут уже отсутствует. Если служба по-прежнему не работает, сообщите об ошибке
вместо удаления других элементов управления безопасностью.

<a id="let-caspian-set-itself-up-and-save-its-password"></a>
#### Позвольте компании «Caspian» настроиться и сохранить свой пароль.

1. Запустите **Caspianский Контроль**. Он сравнивает встроенную фоновую службу с
установленный перед проверкой панели.
2. При первом запуске или когда DMG содержит обновление, запускается установка.
автоматически. Введите пароль администратора при авторизации macOS
диалог. Если установленная версия уже соответствует, пароль не запрашивается.
3. Подождите, пока в окне управления не появится сообщение **Caspian готов**. Если авторизация есть
отменено, **Настроить Caspian** или **Обновить Caspian** остаются видимыми для повторной попытки.
4. При первой установке сохраните **пароль панели первого запуска**, указанный в
выход. **Копировать пароль панели** копирует только этот пароль.
5. Нажмите **Открыть панель** и войдите в систему, используя сохраненный пароль панели.
6. Введите имя и пароль Wi-Fi, вставьте конфигурацию прокси-сервера, затем используйте
переключатель на панели для запуска Каспиана.

Пароль для входа в Mac, пароль панели Каспиан и пароль Wi-Fi — три.
разные пароли. Если пароль панели утерян, используйте **Сбросить пароль** в
Caspianский контроль; требуется авторизация администратора, но сохраненный прокси
и настройки точки доступа остаются. При закрытии окна управления остается строка меню.
предмет работает; выберите там **Открыть Caspianский контроль**, чтобы открыть его снова.

В macOS при закрытии окна управления Каспиан остается в строке меню. Выбор
**Выйти из Каспиана и остановить службы** останавливает точку доступа и фоновые службы.
Если авторизация macOS отменена или остановка не удалась, приложение остается открытым.
При следующем запуске Каспиан запускает остановленные сервисы один раз, с авторизацией администратора.

<a id="forgotten-panel-password"></a>
### Забыл пароль от панели

На компьютере «Caspian» запустите эту команду в терминале или сеансе SSH:

```bash
sudo /usr/local/bin/caspian reset-password
```

Команда печатает новый пароль панели и перезапускает панель. Ваш прокси и
Настройки Wi-Fi сохраняются. Используйте новый пароль на странице входа. В Windows,
запусти `& "$env:ProgramFiles\Caspian\caspian.exe" reset-password` от имени администратора
Окно PowerShell. Переустановка Каспиана не сбрасывает ваш пароль.

<a id="verifying-a-download-yourself"></a>
### Проверка загрузки самостоятельно

Каждый выпуск содержит файл `SHA256SUMS`. Установщик проверит это за вас и
вы можете проверить это самостоятельно:

локон -fsSLO https://github.com/Iman/caspian/releases/latest/download/caspian-linux-arm64
локон -fsSLO https://github.com/Iman/caspian/releases/latest/download/SHA256SUMS
sha256sum -c SHA256SUMS --игнорировать отсутствие

Что это доказывает, а что нет: это доказывает, что файл, который у вас есть, является файлом
релиз опубликован. Это не доказывает, кто создал этот выпуск. Бинарные файлы
создаются с помощью GitHub Actions на основе помеченного коммита и рабочего процесса, который создает
они находятся в этом репозитории по адресу [`.github/workflows/release.yml`](https://github.com/Iman/caspian/blob/main/.github/workflows/release.yml), поэтому сборка
читабелен, даже если его невозможно воспроизвести независимо.

<a id="manual-build-it-yourself"></a>
#### Руководство: собери сам

Ничего об автоматизированном маршруте не требуется. Сборка из исходного кода требует Go
1.26 или более поздней версии и дает идентичный по функциям двоичный файл.

git-клон https://github.com/Iman/caspian.git
компакт-диск Caspianский
иди создай -trimpath -o каспийский ./cmd/caspian
sudo CASPIAN_LOCAL_BINARY="$PWD/caspian" bash install.sh

`CASPIAN_LOCAL_BINARY` сообщает установщику использовать только что созданный файл.
чем загружать его. Все остальное делает установщик, создавая сервис
учетная запись, каталоги, модули и их разрешения, происходит таким же образом.

Кросс-компиляция Pi с другой машины:

GOOS=linux GOARCH=arm64 go build -trimpath -o caspian-linux-arm64 ./cmd/caspian
GOOS=linux GOARCH=arm GOARM=6 go build -trimpath -o caspian-linux-arm ./cmd/caspian

`GOARM=6` в 32-битной сборке не является обязательным. Оба `armv6l` и `armv7l`
машины устанавливают один и тот же артефакт `arm`, поэтому сборка ARMv7 ломается на каждом Pi 1,
Zero и Zero W, которые его устанавливают. Рабочий процесс выпуска проверяет это с помощью
`readelf` и терпит неудачу, вместо того, чтобы публиковать артефакт, который лжет о его
архитектура.

Прежде чем доверять сборке, запустите гейт:

сценарии bash/gate.sh

Он запускает форматирование, проверку, весь пакет с детектором гонок, для каждого пакета.
полы покрытия, золотой регрессионный слой, сканирование конфиденциальности и дым
подмножество. В случае неудачи он завершается ненулевым результатом. Никуда не подводить: оболочковый конвейер
сообщает о статусе своей последней команды, поэтому передача ее в `tail` выбрасывает
ответ, который вы просили.
