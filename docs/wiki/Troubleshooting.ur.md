پہلے ویب پینل کا پیغام پڑھیں۔ اگر Caspian Control میں Ready ہو مگر پینل سرخ ہو تو پراکسی کو متصل نہ سمجھیں۔

- پراکسی لنک پڑھا نہ جا سکے تو نقل کردہ متن دیکھیں۔
- ترتیبات پڑھ لی جائیں مگر قبول نہ ہوں تو انگریزی پروٹوکول رہنمائی میں معاون فارمیٹ دیکھیں۔
- سرور جواب نہ دے تو ترتیبات بدلنے سے پہلے انٹرنیٹ اور سرور تک رسائی جانچیں۔
- macOS کا انتباہ ہو تو اردو macOS رہنمائی پر عمل کریں۔ نقصان دہ سافٹ ویئر کا نام بتانے والا انتباہ نظر انداز نہ کریں۔
- macOS پر پینل کا پاس ورڈ بھول جائیں تو Caspian Control میں Reset password استعمال کریں۔

سکیورٹی کے رویے پر انحصار کرنے سے پہلے انگریزی رہنمائی میں معلوم نقائص پڑھیں۔ مسئلہ رپورٹ کرتے وقت نظام، ریلیز نمبر، اقدامات اور اصل خرابی شامل کریں۔ پاس ورڈ، سبسکرپشن لنک، سرور پتے اور آلے کی شناخت ہٹا دیں۔
