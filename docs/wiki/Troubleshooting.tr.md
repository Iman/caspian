# Sorun giderme

[English](https://github.com/Iman/caspian/wiki/Troubleshooting) | [فارسی](https://github.com/Iman/caspian/wiki/Troubleshooting.fa) | [Русский](https://github.com/Iman/caspian/wiki/Troubleshooting.ru) | [中文](https://github.com/Iman/caspian/wiki/Troubleshooting.zh) | [العربية](https://github.com/Iman/caspian/wiki/Troubleshooting.ar) | [اردو](https://github.com/Iman/caspian/wiki/Troubleshooting.ur) | [Türkçe](https://github.com/Iman/caspian/wiki/Troubleshooting.tr)

Önce web panelindeki mesajı okuyun. Caspian Control Ready gösterirken panel kırmızıysa proxy bağlantısının kurulduğunu varsaymayın.

- Proxy bağlantısı okunamıyorsa kopyaladığınız metni kontrol edin.
- Yapılandırma okunuyor ancak reddediliyorsa İngilizce protokol kılavuzundaki desteklenen biçimleri inceleyin.
- Sunucu yanıt vermiyorsa yapılandırmayı değiştirmeden önce internet bağlantısını ve sunucuya erişimi kontrol edin.
- macOS uyarılarında Türkçe macOS kılavuzunu izleyin. Zararlı yazılım adı veren bir uyarıyı geçmeyin.
- macOS'ta panel parolasını unutursanız Caspian Control içindeki Reset password seçeneğini kullanın.

Güvenlik davranışına güvenmeden önce İngilizce kılavuzdaki bilinen kusurları okuyun. Hata bildirimine işletim sistemini, sürüm numarasını, adımları ve hata metnini ekleyin. Parolaları, abonelik bağlantılarını, sunucu adreslerini ve cihaz kimliklerini çıkarın.
