# ساخت محلی Windows

نسخهٔ انگلیسی مرجع این سند است. آزمون‌ها برابری شناسه‌ها و پیوندها را بررسی می‌کنند.
از پوشهٔ مخزن اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-windows.ps1
```

این فرمان برنامهٔ Go، ابزار کمکی هات‌اسپات، برنامهٔ دسکتاپ و نصب‌کننده را می‌سازد.
نسخهٔ پیش‌فرض `0.0.0` و معماری پیش‌فرض `x64` است.
ساخت به دسترسی مدیر نیاز ندارد.

ابزارهای لازم:

- Go 1.26 یا جدیدتر
- .NET SDK 9 یا جدیدتر
- Inno Setup 6 در پوشهٔ نصب استاندارد یا روی `PATH`

Go و .NET باید روی `PATH` باشند.
اولین ساخت برای وابستگی‌ها و Wintun به اینترنت نیاز دارد.
ساخت Wintun را در `.cache` ذخیره و در هر اجرا چک‌سام آن را مقایسه می‌کند.
چک‌سام محتوای مورد انتظار فایل را مشخص می‌کند.

برای نسخهٔ مشخص یا ARM64 اجرا کنید:

```powershell
.\build-windows.ps1 -Version 1.2.3 -Architecture arm64
```

خروجی‌ها:

- نصب‌کننده: `out\installer\CaspianSetup-0.0.0-windows-x64.exe`
- چک‌سام نصب‌کننده: همان مسیر با پسوند `.sha256`
- برنامه و ابزارهای کمکی: `packaging\windows\installer\payload\x64\`

مسیرها نسخه و معماری انتخاب‌شده را به کار می‌برند.
نصب‌کننده محیط اجرای .NET و Wintun را شامل می‌شود.
فرمان نصب‌کننده را می‌سازد اما آن را اجرا نمی‌کند.
اجرای نصب‌کننده به دسترسی مدیر نیاز دارد.

این فرمان از همان سازندهٔ گردش کار انتشار استفاده می‌کند.
اگر ساخت یا مقایسهٔ نسخه، معماری یا چک‌سام شکست بخورد، متوقف می‌شود.
مجموعهٔ کامل آزمون‌ها را اجرا نمی‌کند.

## فایل‌های جعل SNI

ساخت x64 همچنین WinDivert 2.2.2-A و آرشیو منبع v2.2.2 را دریافت می‌کند.
اسکریپت پیش از بسته‌بندی هر آرشیو، هش SHA256 ثابت‌شده را بررسی می‌کند.
نصب‌کننده DLL، درایور امضاشده، آرشیو منبع، مجوز و انتساب را شامل می‌شود.
ساخت ARM64 بدون WinDivert است و جعل SNI را پشتیبانی نمی‌کند.
[تنظیم SNI](SNI.fa.md) و [مجوزهای شخص ثالث](THIRD-PARTY.fa.md) را ببینید.
